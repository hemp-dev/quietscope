# quietscope Documentation Assets 🖼️

Place all screenshots, diagrams, and demo GIFs for the project's documentation in this directory.

Recommended assets to prepare:
1. **`dashboard.png`**: A screenshot of the self-contained HTML report opened in a browser.
2. **`cli_demo.gif`**: A short recording of running the CLI tool (e.g., using `asciinema` or a GIF recorder).
3. **`desktop_preview.png`**: A screenshot of the Wails native desktop app window.

To link these in your main `README.md`, you can use standard markdown:
```markdown
![quietscope Dashboard](./docs/assets/dashboard.png)
```
